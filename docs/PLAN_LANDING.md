## 2. Technical Design: Interactive Mini-Demo

**Core Concept:** A sandboxed HTML/CSS mock component inside the landing page that behaves _exactly_ like the real Pointr extension.

**State Management (Vanilla JS):**

- `isAltPressed`: boolean, tracking `keydown` and `keyup` for the Alt/Option key.
- `hoveredElement`: the currently targeted DOM node in the demo area.
- `pointrModalState`: hidden | visible (with coordinates).

**Interactivity Flow:**

1. **Hover State**: When `isAltPressed` is true, the `mousemove` event tracks elements inside the `#demo-container`. The element gets a blue outline (`#3b82f6`) and a tooltip shows its simulated file/line (e.g., `Button.tsx:42:5`).
2. **Click State**: User clicks while Alt is pressed.
   - A floating Pointr dialog (CSS absolute positioned) appears at the click coordinates.
   - The dialog contains a textarea for the prompt.
3. **Action State**: User types a prompt ("Make this button emerald") and hits Enter.
   - _Visual Feedback_: The clicked button's background smoothly transitions to Emerald (`#10b981`).
   - _Code Panel_: The adjacent code panel types out the resulting Markdown/JSON payload generated by Pointr.

## 3. Animation Scripts & Visual Feedback

**Target Cursor / Crosshair Pointr:**

- A custom SVG cursor or a floating DOM element (`div#pointr-crosshair`) that follows the mouse.
- **CSS**:
  ```css
  #pointr-crosshair {
    position: fixed;
    pointer-events: none;
    transition: transform 0.1s ease-out;
    mix-blend-mode: difference;
  }
  ```
- **JS**: Track `mousemove` and `requestAnimationFrame` for smooth interpolation. When snapping to an element, transform the crosshair to frame the element's bounding box.

**Metaphor Glitch / Falling Text:**

- A CSS animation applied to text spans.
- **CSS**:
  ```css
  @keyframes glitch-fall {
    0% {
      transform: translateY(0);
      opacity: 1;
      filter: blur(0);
    }
    50% {
      transform: translateY(10px) skewX(20deg);
      opacity: 0.5;
      filter: blur(2px);
    }
    100% {
      transform: translateY(50px);
      opacity: 0;
      filter: blur(4px);
    }
  }
  .glitch-text {
    animation: glitch-fall 2s infinite;
    color: #94a3b8;
  }
  ```

**Color Palette Enforcement:**

- Dark Background: `#0a0a0f`
- Primary Blue (Pointr): `#3b82f6`
- Success/Action Emerald: `#10b981`
- Text: `#ffffff`
- Muted/Secondary Text: `#94a3b8`
- _Strict Rule: No purple/violet hex codes anywhere in the stylesheet._
