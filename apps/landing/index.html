Packages

@pointr/vite-plugin

Injects the Pointr overlay into your running Vite application.

@pointr/mcp-server

Connects your AI agent to the Pointr overlay securely via MCP.

@pointr/core

Core logic and DOM inspection utilities used across the ecosystem.

@pointr/types

Shared TypeScript definitions for the Pointr ecosystem.

Quick Start

# 1. Install Vite plugin
npm install -D @pointr/vite-plugin

# 2. Add to vite.config.ts
import { pointr } from '@pointr/vite-plugin';
export default defineConfig({
  plugins: [pointr()]
});

# 3. Start MCP server
npx @pointr/mcp-server
